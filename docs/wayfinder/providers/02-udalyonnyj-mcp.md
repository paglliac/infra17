## Question

Может ли Claude Code подключаться к MCP-серверу на `gang.su` по адресу (HTTP/streamable HTTP) с токеном так, чтобы на маке не лежало никакого кода? Как это прописать один раз на все проекты (user scope, плагин, managed settings), как передаётся токен, что с перезапуском и обновлением списка инструментов, есть ли ограничения (таймауты, размер ответа, OAuth vs bearer)? Как то же самое делают сервисы с `claude: true` на сервере (recaps, go)?

## Research

Находки: ветка `research/udalyonnyj-mcp`, файл `docs/research/udalyonnyj-mcp.md`.

## Решение

Да, на маке кода может не быть вовсе: Claude Code подключается к MCP на сервере по HTTP, SSE устарел. Подробности и источники — `docs/research/udalyonnyj-mcp.md` в ветке `research/udalyonnyj-mcp`.

- **Подключение**
  - на весь мак: одна строка `claude mcp add --transport http --scope user …`;
  - токен: `Authorization: Bearer ${VAR}` в `headers` или через `headersHelper` (например, из Keychain).
  - Не подтверждено: какие имена переменных Claude Code обнуляет для удалённых серверов. Проверить на своём имени.
- **Раздача**
  - подходит плагин: `userConfig` один раз спрашивает токен и хранит его в защищённом хранилище;
  - managed settings не подходят: значения в них читает любой на машине, а `managed-mcp.json` выключает все остальные серверы.
- **Ограничения**
  - каждый HTTP-запрос к удалённому серверу — 60 с по умолчанию, для долгих инструментов нужен `timeout` у сервера;
  - ответ — до 25k токенов;
  - список инструментов обновляется без переподключения;
  - если сервер лежит, `-p` работает без него и пытается переподключиться в фоне.
- **Один сервер или много**
  - лимита на число инструментов нет, описания грузятся по мере надобности;
  - с одним сервером нельзя отключить одного поставщика в `/mcp`, только правилами deny.
- **Сервисы на сервере:** `claude -p --strict-mcp-config --mcp-config <файл>`, токен из окружения сервиса.
- **Сервер на Python**
  - по спеке 2026-07-28 сервер stateless;
  - в SDK v2 `FastMCP` переименован в `MCPServer`;
  - за Caddy нужен `allowed_hosts`, иначе 421;
  - Caddy ничего дополнительно не требует.
