## Question

Мотор — один сервис, внутри которого модули Mattermost, Confluence и остальные, или отдельный сервис на каждого поставщика с общим входом впереди?

## Решение

Один мотор — один сервис на `gang.su`, код всех поставщиков в нём. Но наружу каждый поставщик — отдельно: у каждого свой адрес MCP (`…/mattermost`, `…/confluence`, …), и проект подключает только нужных. Поставщики, которые проекту не нужны, в нём не появляются.

> Уточнено в «Как проект подключает нужных поставщиков» (06): выбора по проектам нет — всем потребителям все поставщики. Отдельные адреса остаются, чтобы в `/mcp` можно было выключить одного.
