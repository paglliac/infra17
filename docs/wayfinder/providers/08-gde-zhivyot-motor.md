## Question

В каком репо лежит код мотора (новая программа, не `tasks17`) и плагин «мотор» для мака (см. «Как проект подключает нужных поставщиков»)? Как мотор деплоится на `gang.su` — запись в `services.yml`, как у остальных сервисов? Как туда же попадает общий `--mcp-config` для сервисов с `claude: true`?

## Решение

- **Репо** — своё, например `paglliac/motor`: в нём код мотора и плагин «мотор» для мака.
- **Деплой** — запись `motor` в `group_vars/all/services.yml` этого репо, как у budget и recaps: свой порт, поддомен `motor.gang.su`, `.env`, `health`, `make deploy S=motor`. Своего `deploy/` у мотора нет.
  - Общее правило: все деплои живут в `infra`. Перенос деплоя SecondBrain сюда — отдельная работа, не эта карта.
- **Общий файл подключения для `claude -p`** — один на сервер, кладёт его этот репо (например `/etc/motor/mcp.json`): адреса всех поставщиков, токен подставляется из окружения сервиса (`${MOTOR_TOKEN}`). Его берут все сервисы с `claude: true` и SecondBrain.
  - Проверить при сборке: подставляет ли Claude Code переменную окружения в заголовок из `--mcp-config` (тот же вопрос, что в «Как проект подключает нужных поставщиков»).
- **Токен сервиса** — руками: выписать на страничке мотора, потом `make env S=<сервис> K=MOTOR_TOKEN`.
- **Обход NL-адреса**: когда ktalk и Exchange переедут из хаба в мотор, `avito.ktalk.ru` и `exchange.avito.ru` уходят из `direct_taken` у SecondBrain в `direct` у мотора; ZenMoney (`api.zenmoney.ru`) — так же из `direct` у budget, когда budget переедет на мотор.
